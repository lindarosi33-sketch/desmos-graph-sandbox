# -- AC Circuits --
Graph a 60 Hz sine wave with 170 V peak amplitude over 3 periods

Graph a 1 kHz triangle wave over 2 periods with 5 V amplitude
Graph a 5 V peak-to-peak square wave at 100 Hz over 3 periods

# -- Transient Response --
Graph RC charging: v(t) = 12(1 - e^(-t/0.1)) for t ≥ 0
Graph RC discharging: v(t) = 12 e^(-t/0.1) for t ≥ 0
Graph RLC underdamped response: v(t) = 10 e^(-2t) cos(10t) for t ≥ 0
Graph RL step response: i(t) = 5(1 - e^(-t/0.05)) for t ≥ 0
Graph critically damped RLC: v(t) = 10(1 + 5t)e^(-5t) for t ≥ 0

# -- Rectification --
Graph half-wave rectified sine: max(sin(x), 0) over 0 to 4π
Graph full-wave rectified sine: |sin(x)| over 0 to 4π
Graph a 5 V DC offset sine: 5 + 3 sin(x) over 0 to 4π
Graph diode clipping: clip sin(x) at -0.7 and 0.7
Graph voltage doubler output: |sin(x)| + 1 over 0 to 4π

# -- Filter Responses --
Graph low-pass filter magnitude: 1 / sqrt(1 + (f)^2) for f = 0 to 10
Graph high-pass filter magnitude: f / sqrt(1 + f^2) for f = 0 to 10
Graph band-pass filter: f / sqrt((1 - f^2)^2 + (0.1 f)^2) for f = 0 to 5
Graph integrator output: -∫sin(t) dt from 0 to x = cos(x) - 1
Graph differentiator output: d/dx sin(x) = cos(x)

# -- Fourier Series --
Graph square wave approximation: sum from n=1 to 5 of (sin((2n-1)x) / (2n-1)) * (4/π)

Graph triangle wave: sum from n=0 to 5 of ((-1)^n sin((2n+1)x) / (2n+1)^2) * (8/π^2)
Graph first 3 harmonics: sin(x) + 0.5 sin(3x) + 0.33 sin(5x)
Graph AM spectrum: sin(20x) + 0.25 sin(18x) + 0.25 sin(22x)

# -- Power --

Graph apparent power: sqrt(P^2 + Q^2) for P = 0 to 100 with Q = 50
